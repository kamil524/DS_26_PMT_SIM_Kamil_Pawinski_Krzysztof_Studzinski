# DS_26_PMT_SIM_Kamil_Pawinski_Krzysztof_Studzinski
PMT Simulator project developed at AGH University of Krakow as part of DSlab, related to the ALICE experiment.  Project supervisor: MSc Eng. Sebastian Koryciak.

PMT-SIM – Project Goals and Milestones
Main Project Goal
The main goal of this project is to develop a system that allows controlling pulses generated by a photomultiplier tube (PMT) simulator from a computer using a Raspberry Pi Pico microcontroller.
The system will provide the ability to adjust control voltages using a digital-to-analog converter (DAC), trigger pulses, and control their timing parameters. The programmable I/O blocks (PIO) of the RP2040 microcontroller will be used to generate precise control signals.

1. Hardware Documentation and Design Analysis
   
Goal: Understand the hardware structure of the PMT simulator and the communication methods used by its electronic components.

Scope of work:
- Analyze the electronic schematics and PCB design of the PMT-SIM board.
- Study the architecture and operation of the AD5361 DAC.
- Analyze the circuit responsible for pulse generation.
- Identify the HIT1 and HIT2 control signals and the V_CAL_HIT1 and V_CAL_HIT2 calibration voltages.
- Analyze the PMOD–EEM adapter schematic.
- Determine how to connect the Raspberry Pi Pico to the simulator board.
  
Expected result: Understanding the hardware architecture of the simulator and preparing a plan for controlling it using the Raspberry Pi Pico.

2. Establishing Communication Between Raspberry Pi Pico and the Simulator Board
   
Goal: Establish communication between the microcontroller and the electronic components of the simulator.

Scope of work:
- Set up the development environment for the Raspberry Pi Pico.
- Prepare a basic program in C.
- Configure the SPI interface for communication with the DAC.
- Configure the required control and communication signals.
- Verify correct data transmission between the microcontroller and the simulator board.
  
Expected result: Working communication between the Raspberry Pi Pico and the PMT-SIM electronics.

3. Implementation of DAC Control
   
Goal: Enable software-based adjustment of analog voltages that affect the parameters of the generated pulses.

Scope of work:
- Study the configuration and communication protocol of the AD5361 DAC.
- Implement communication with the DAC using the SPI interface.
- Develop functions for DAC initialization and configuration.
- Implement voltage setting on selected DAC channels.
- Implement control of the V_CAL_HIT1 and V_CAL_HIT2 calibration voltages.
- Verify the output voltages using measurement equipment.
  
Expected result: The ability to programmatically set and adjust calibration voltages for individual simulator channels.

4. Learning and Using Programmable I/O (PIO) Blocks
   
Goal: Use the programmable I/O blocks of the RP2040 microcontroller to generate precise and repeatable control signals.

Scope of work:
- Study the architecture and capabilities of the PIO blocks.
- Learn how to program state machines.
- Develop PIO programs responsible for generating digital control signals.
- Use PIO to achieve precise timing control of generated signals.
- Develop a method for transferring parameters and commands between the main processor and PIO blocks.
- Verify the generated waveforms using an oscilloscope.

Expected result: A mechanism for generating precise and repeatable control signals using PIO, which can be used to trigger PMT pulses.

5. Implementation of Pulse Generation Control
   
Goal: Enable control over the triggering of pulses that simulate signals produced by a photomultiplier tube.

Scope of work:
- Analyze the operation of the pulse-triggering circuit.
- Implement control of the HIT1 and HIT2 signals using the Raspberry Pi Pico.
- Use programmable PIO blocks to generate trigger signals.
- Develop a method for controlling pulse triggering times and time intervals between pulses.
- Implement independent control of both channels.
- Perform tests and measurements of the generated pulses.
  
Expected result: The ability to independently trigger HIT1 and HIT2 pulses and control their timing parameters using the Raspberry Pi Pico.

6. Development of a Python Control Interface
   
Goal: Enable control of the PMT simulator directly from a computer.

Scope of work:
- Develop communication between the computer and the Raspberry Pi Pico.
- Create a Python program for sending commands to the microcontroller.
- Implement the ability to adjust DAC calibration voltages.
- Add functions for triggering HIT1 and HIT2 pulses.
- Enable configuration of the timing parameters of the generated pulses.
- Develop a simple interface for convenient simulator configuration and operation.
  
Expected result: The ability to control voltages, pulse triggering, and pulse timing parameters from a computer using a Python application.

7. System Integration, Testing and Documentation
   
Goal: Integrate all developed components and verify the correct operation of the complete system.

Scope of work:
- Integrate the Raspberry Pi Pico firmware with the Python interface.
- Test communication with the DAC.
- Verify the accuracy of the configured calibration voltages.
- Test PIO operation and HIT1/HIT2 pulse triggering.
- Verify the stability and repeatability of the generated signals.
- Perform measurements using an oscilloscope and other available measurement equipment.
- Prepare technical documentation and a demonstration of the final solution.
  
Expected result: A complete system that allows controlling PMT simulator pulses from a computer through the Raspberry Pi Pico.
